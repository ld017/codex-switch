# Codex Switch 2.3.3（macOS）

本版本将菜单栏主菜单顶部的多行环境状态收为一个可展开的连接入口，账号与额度操作更靠前，保留两个提供方切换动作、共享刷新、账号管理和定时预热。

## 更新内容

- 主菜单顶部只保留一个连接入口：`连接：OpenAI 官方`、`连接：Sub2API`，当前 Sub2API 端口检查失败或配置无法读取时在同一入口表达注意状态。
- Sub2API 端口、代理环境风险、代理预检、共享启动配置和诊断更新时间移入连接子菜单；备用通道失败、代理预检不匹配或共享检查失败不会把当前 OpenAI 连接标成断网。
- 诊断改为按需采样并缓存60秒，单一采样槽等待实际 source 工作结束；provider 变化、取消、恢复和慢异步结果不会覆盖新状态。
- 子菜单持有稳定的菜单项，不触发主菜单重建、账号刷新或 Token 明细丢失。
- 保留 WarmupService 的启动、取消等待、状态入口和退出等待；本版本没有为验收发送真实模型请求。

## 下载与安装

下载 `Codex-Switch-2.3.3-macOS-arm64.zip`，解压后将 `Codex Switch.app` 放入 `~/Applications/`，再打开。`SHA256SUMS.txt` 提供 SHA-256 校验值。

- 适用 Apple Silicon；最低 macOS 14；使用 ad-hoc 签名，未经过 Apple 公证。
- 安装包只包含应用程序，不包含账号凭据、配置或用量记录；已有账号数据继续保存在用户目录。
- 本次 Release 只提供 macOS 版本，Windows 版本保持独立。

## 验证边界

- 全量 XCTest 189 项，其中2项真实环境测试按规则跳过；Swift Testing 111 项；均无失败。
- Release 构建、strip、签名、应用和 ZIP 隐私检查通过；重新下载的发布资产已复核 SHA-256 和隐私扫描。
- 已核对安装进程路径、旧版备份及预热计划指纹；没有执行真实切号、立即预热或模型请求。
- 由于 CUA 原生菜单读取超时，现场菜单视觉和悬停行为未宣称通过；组件测试和代码审查结果不替代现场视觉验收。
