# Codex Switch 2.3.5（macOS，build 14）

本版本将账号卡片改为随原生菜单宽度伸展，在主额度行同排显示服务端报告的北京时间重置时刻与倒计时，并统一 macOS 界面的北京时间口径。

## 更新内容

- 账号卡、标题区和分隔线共用可伸缩宽度；基础宽度 340pt，窗口名称列可完整容纳“5小时”，两条额度行的进度条、百分比及时间列对齐。
- 主额度行使用服务端 `primaryResetAt` 显示具体重置时刻与倒计时。跨日、缓存、未返回和等待刷新均有明确标记；长文字使用保留日期与状态的紧凑文案。
- 时间已到但尚未取得新读数时显示“待刷新”，不以时间经过认定额度已恢复或预热成功。Token 接口单独失败不把有效额度标为缓存。
- 悬停及无障碍说明提供完整年月日、秒、北京时间及剩余时长。窗口名称按服务端 duration 命名，缺失时使用“主窗口”。
- 界面读取时间、到期时间、连接诊断、预热计划和“本月”筛选使用北京时间；服务端日桶仍保留原日期，不重新推定每笔消耗所属日期。
- 可见菜单沿用本地分钟时钟，在系统校时或唤醒后重算缓存显示；时间重绘不额外发起额度请求、端口探测或模型请求。
- 保留紧凑连接子菜单、Token 详情、账号/provider 切换、共享历史、定时预热、取消及退出等待。

## 下载与安装

下载 `Codex-Switch-2.3.5-macOS-arm64.zip`，解压后将 `Codex Switch.app` 放入 `~/Applications/`，再打开。升级前正常退出旧版菜单栏工具。

- Apple Silicon（arm64），最低 macOS 14。
- 使用 ad-hoc 签名，未进行 Apple 公证。
- 安装包只包含应用程序，不包含账号凭据、配置、缓存、日志、预热计划或个人截图；已有账号数据继续保存在用户目录。
- 本次只更新 macOS 安装包，Windows 版本独立发布。
