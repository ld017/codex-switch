# Codex Switch 2.3.2（macOS）

修复新版Codex接口导致额度刷新失败的问题，并降低刷新峰值和共享历史代理的临时资源占用。

## 更新内容

- 兼容重置卡明细为null或缺省的响应；保留可用数量，未返回的到期时间显示为未知。
- 额度取得后立即更新，逐账号展示刷新进度，不再等待全部账号和Token接口完成。
- 查询CLI最多同时运行一个，当前账号优先；完整Token统计15分钟内复用，手动刷新重新获取。
- 合并重复强刷，取消后等待旧查询退出，防止短暂进程交叠或旧结果回写。
- 菜单展开期间更新已有视图；Token详情按需从缓存构建菜单项，失败原因保留为短脱敏信息。
- 共享历史代理采用线性长行扫描、直接Data改写和分段临时对象释放；服务状态探测降低频率并防重入。
- 兼容新版Codex CLI在嵌套应用或bin目录中的布局，保留旧路径支持。

## 下载与安装

下载 `Codex-Switch-2.3.2-macOS-arm64.zip`，先退出已有Codex Switch，解压后将 `Codex Switch.app` 放入 `~/Applications/`，再打开。附件 `SHA256SUMS.txt` 提供SHA-256校验值。

- 适用Apple Silicon；应用声明最低macOS 14，本轮在macOS 26验证。
- 使用ad-hoc签名，未经过Apple公证；如系统无法验证开发者，可按系统支持的方式处理或从源码构建。
- 安装包仅包含应用程序，不包含账号凭据、配置或用量记录。
- 已有账号数据继续保存在用户目录。新版共享代理随新进程加载；正在运行的Codex不会热替换。
- 本次附件仅提供macOS版本；Windows 1.0.6下载入口保持独立。

## 验证与资源结果

141项XCTest（1项按设定跳过）及74项Swift Testing，无失败；release构建、签名完整性和本机多账号只读查询通过。

同一组100 MiB合成请求、三次中位数：Swift代理最大RSS约100.7→12.6 MB，耗时2.84→0.50秒。单个超大请求峰值内存并非都下降，这些数字不代表整机内存收益。Token日统计仍受服务端更新延迟影响。
