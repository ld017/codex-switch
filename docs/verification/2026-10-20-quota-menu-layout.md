# macOS 账号菜单铺满与北京时间重置时刻验收

实施版本：**2.3.5（build 14）**。公开源码分支：`codex/quota-menu-layout-2.3.5`。

公开提交从已发布的 v2.3.3 基线整理，包含北京时间统一、菜单宽度和重置时刻改动，保留预热、紧凑连接菜单和安装隐私门禁。本地实施历史独立保留，公开历史不包含旧测试中的个人绝对路径；该历史整理不改变已验证的产品代码。

## 实现结果

- Header、账号卡、分隔线采用共享 340pt 初始宽度与宽度 autoresizing，内部允许横向铺满；未建立 `menu.size` 与 host 宽度的反馈循环。
- 名称、百分比、时间列分别为 34/30/144pt，基础宽度下进度条至少 100pt；两条额度行共用列位置。真实 300 分钟窗口显示“5小时”，缺少 duration 时显示“主窗口”。
- 主窗口同排显示服务端 `primaryResetAt` 的北京时间时刻和倒计时。长文案选择完整的紧凑候选，保留日期、缓存和待刷新状态，时间字号仍为 9pt。
- 同批 header/card 使用同一个 `now`。本地时间更新沿用 `VisibleTimeClock`，只重算缓存；未修改额度请求、连接探测、预热发送或计时器策略。
- 仅 Token 接口失败时不把有效 quota 标成缓存。过去的报告显示“待刷新”，不能据此判断额度已恢复或预热成功。
- 本次补齐悬停/无障碍说明的完整剩余天、小时、分、秒；修正离屏测试写死个人目录和未覆盖生产卡片高度的问题。
